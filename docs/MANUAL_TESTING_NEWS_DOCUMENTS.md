# Ручная проверка новостей, документов, файлов и офлайн-состояний

Задачи: #17, #23, #28, #29, #33. Выполняйте этот список на собранной новой версии приложения.
Ставьте отметку только после совпадения фактического результата с ожидаемым; если нужного контента нет, помечайте проверку «не выполнено: нет тестовых данных».

## Подготовка

1. Основной прогон: реальное устройство или исправный эмулятор. Для файлов отдельно проверить Android 10 / API 29 и Android 14 / API 34; дополнительно проверить целевую Android 17 / API 37.
2. Установить APK обновлением поверх прежней версии через Run в Android Studio, сохранив данные приложения. Для проверки миграции заранее сохранить несколько избранных групп и преподавателей и поменять их порядок.
3. Для сценариев без кэша использовать отдельную чистую установку на тестовом устройстве. Удаление приложения или очистка его данных удаляет локальные настройки и избранное, поэтому не делайте это на основной установке.
4. Установить просмотрщики PDF, DOCX и XLSX, а также любое приложение, принимающее файлы через «Поделиться».
5. Для сетевых сценариев выключать одновременно Wi-Fi и мобильный интернет. Если на эмуляторе режим полёта оставляет Wi-Fi включённым, выключить Wi-Fi отдельно.
6. Для форматирования и вложений нужна тестовая статья с h2/h3, абзацами, жирным/курсивным текстом, маркированным и нумерованным списками, цитатой, ссылками, картинками и файлами PDF/DOCX/XLSX. Для документов нужны минимум две категории, пустая категория и по одному файлу каждого формата.
7. На момент реализации публичный `/documents` возвращал пустой список категорий. Пустой экран с пояснением в таком случае — ожидаемый результат. Остальные сценарии документов требуют публикации тестовых документов владельцем сервера; приложение не подменяет их демонстрационными файлами.

## Обновление и основной запуск

- [ ] **Миграция базы.** На прежней версии запомнить выбранное расписание, избранное и его порядок. Установить новую версию поверх неё и открыть приложение. Ожидается: запуск без сброса БД; избранное, порядок и выбор сохранены.
- [ ] **Повторный запуск.** Закрыть приложение, убрать его из недавних и открыть снова. Ожидается: запуск без зависания, выбранное расписание и ранее скачанные файлы доступны.
- [ ] **Навигация.** Переключить все четыре вкладки, открыть новость и документ, вернуться кнопкой приложения и системной «Назад». Ожидается: переход в правильный список, а не выход из приложения или открытие другого материала.

## Новости

- [ ] **Первичная загрузка.** При включённом интернете открыть «Новости». Ожидается: во время запроса видны скелетоны, затем реальные заголовки, даты, описания и обложки; демонстрационной статьи о зимней сессии нет.
- [ ] **Каждая карточка кликабельна.** Открыть по очереди первую, среднюю и последнюю новости. Сверить заголовок и текст с выбранной карточкой/ответом API. Ожидается: открывается именно выбранная статья.
- [ ] **Пагинация.** В ленте с более чем пятью новостями прокрутить к концу. Ожидается: подгрузка следующих записей; отсутствуют дубликаты, пропуски и бесконечная загрузка после последней страницы. Кнопка «Загрузить ещё», если видна, тоже работает.
- [ ] **Ошибка следующей страницы.** До подгрузки следующей страницы выключить интернет, затем дойти до конца списка. Ожидается: прочитанные карточки остаются, появляется понятная ошибка/повтор. Включить интернет и нажать повтор — следующая страница загружается один раз.
- [ ] **Обновление ленты.** Потянуть список вниз. Ожидается: индикатор обновления, прежние карточки остаются до результата; после успеха отображаются актуальные данные, индикатор исчезает.
- [ ] **Сохранение места.** Прокрутить ленту, открыть статью и вернуться; затем повернуть устройство. Ожидается: позиция списка сохраняется, приложение не возвращает к самому началу без причины.
- [ ] **Короткий обрыв связи.** Открыть вкладку с загруженными данными, отключить Wi-Fi и мобильную сеть на 1–2 секунды и включить обратно. Повторить в разных вкладках. Если соединение полностью восстановилось за 10 секунд, плашка не появляется, данные остаются видимыми.
- [ ] **Плашка без интернета.** Отключить Wi-Fi и мобильную сеть дольше 10 секунд и по очереди открыть «Расписание», «Поиск», «Новости» и «Документы». В каждой вкладке должна быть одна плашка с оранжевой иконкой слева от «Вне сети» и без кнопки «Обновить». Если известно время сохранения данных экрана, оно указано ниже. Включить интернет: плашка исчезает, неудавшаяся из-за обрыва загрузка повторяется.
  В «Поиске» переключить «Группы» и «Преподаватели». Для каждого сохранённого списка должна быть показана дата и время его сохранения. Поисковый запрос и выбор расписания без кэша не должны сбрасывать эту отметку.
- [ ] **Пустая лента.** На тестовом сервере вернуть `items: []`, `total: 0`. Ожидается: «В ленте пока нет новостей», без бесконечных запросов и пустого белого экрана.

## Полный текст статьи

- [ ] **Форматирование.** Открыть подготовленную статью. Ожидается: заголовки выделены, абзацы разделены, жирный и курсив сохранены, списки и цитаты читаемы; символы `&amp;`, `&nbsp;` и числовые HTML-сущности отображаются как текстовые символы, HTML-теги не видны.
- [ ] **Изображения.** Прокрутить статью с несколькими картинками. Ожидается: фотографии в правильном порядке, без растяжения; обложка не повторяется второй раз в галерее; при нажатии на картинку открывается её адрес.
- [ ] **Повтор загрузки картинки.** Выключить интернет до первого просмотра ещё не загруженного изображения. Ожидается: понятная заглушка с повтором. Включить интернет и нажать её — изображение появляется.
- [ ] **Ссылки.** Нажать веб-ссылку, ссылку Telegram и ссылку источника, если она есть. Ожидается: системное приложение/браузер; если обработчика нет, понятное сообщение без падения. Вернуться в Schedion — статья остаётся открытой.
- [ ] **Отправка статьи.** Нажать «Поделиться новостью». Ожидается: системный выбор приложения; передаются заголовок, описание и ссылка источника, когда она есть. Отмена диалога не закрывает статью.
- [ ] **Обновление статьи.** Потянуть статью вниз. Ожидается: содержание остаётся видимым, а после успешного запроса обновляется.
- [ ] **Поворот и быстрые переходы.** Повернуть устройство в открытой статье; быстро открыть несколько разных новостей через возврат в список. Ожидается: правильная статья, без подстановки текста/картинок от предыдущей.
- [ ] **Удалённая статья.** На тестовом сервере получить 404 для выбранного slug. Ожидается: сообщение о недоступном материале и повтор; с ранее сохранённой статьёй показанный текст сохраняется с сообщением об ошибке обновления.

## Документы

- [ ] **Список и категории.** Открыть «Документы» с подготовленными данными. Ожидается: реальные категории и документы в порядке API, название, описание, формат, размер и дата обновления. Образцов «Календарный график 2026/27» из макета быть не должно, если их нет на сервере.
- [ ] **Фильтры.** Выбрать каждую категорию и «Все». Ожидается: только документы выбранной категории; длинные названия категорий доступны горизонтальной прокруткой; пустая категория содержит пояснение.
- [ ] **Детали документа.** Открыть каждый документ. Ожидается: правильные название, описание, аудитория, дата и файл; возврат ведёт к списку.
- [ ] **Пустой ответ.** При `categories: []` открыть/обновить вкладку. Ожидается: «Документы пока не опубликованы». Сетевую ошибку нельзя выдавать за пустой ответ.
- [ ] **Обновление и удаление.** Обновить список после изменения документа на тестовом сервере. Ожидается: новые данные и категории; удалённый документ не остаётся в свежем списке; 404 в деталях не приводит к падению.

## Скачивание, открытие и отправка файлов

Выполнить отдельно для PDF, DOCX и XLSX в документе и во вложениях статьи.

- [ ] **Загрузка.** Нажать «Скачать». Ожидается: файл ставится в DownloadManager, виден статус/процент, доступно системное уведомление; после завершения появляется «Открыть файл». Файл находится в `Загрузки/Schedion`.
- [ ] **Повторное нажатие.** Несколько раз нажать скачивание одного файла и повторить после завершения. Ожидается: одна активная загрузка и повторное использование уже скачанной версии.
- [ ] **Фоновая загрузка.** Начать скачивание, уйти на другую вкладку, закрыть приложение и открыть его после окончания загрузки. Ожидается: DownloadManager продолжил работу, приложение восстановило статус, файл можно открыть.
- [ ] **Открытие.** Нажать «Открыть файл». Ожидается: подходящий просмотрщик получает содержимое без ошибки доступа; после возврата приложение работает.
- [ ] **Нет просмотрщика.** На отдельном тестовом устройстве без приложения нужного формата открыть файл. Ожидается: понятное сообщение, без падения; скачанный файл сохраняется.
- [ ] **Отправка файла.** Нажать «Поделиться файлом» и выбрать приложение-получатель. Проверить открытие принятого файла. Ожидается: передаётся сам файл с правильным типом и разрешением на чтение, а не локальный путь.
- [ ] **Отправка ссылки.** Нажать «Поделиться ссылкой». Ожидается: передаётся ссылка файла; для этого скачивание не требуется. Отменить системный диалог — приложение остаётся на экране документа/статьи.
- [ ] **Пропавший файл.** Удалить только тестовый скачанный файл через приложение «Файлы», вернуться в Schedion. Ожидается: файл отмечается недоступным, повторное скачивание восстанавливает его; кнопка открытия не приводит к падению.
- [ ] **Новая версия.** Заменить файл тестового документа и изменить его `updatedAt` на сервере, обновить детали и скачать. Ожидается: новая версия скачивается отдельно; старая версия не открывается как актуальная.
- [ ] **Ошибка загрузки.** Использовать на тестовом сервере файл с 404/503 или прервать интернет во время скачивания. Ожидается: ожидание сети либо ошибка с повтором; после восстановления сети/ссылки скачивание завершается. Процент не зависает навсегда на 100% для ошибочного файла.
- [ ] **Имена файлов.** Проверить длинное имя, пробелы, кириллицу и одинаковые имена у разных файлов. Ожидается: правильное содержимое каждого файла, отсутствие коллизий и ошибок пути.
- [ ] **Android 10 и 14.** Повторить скачивание/открытие/отправку. Ожидается: нет запроса широкого доступа к хранилищу; операции работают через системные content URI.

## Офлайн и общие состояния

- [ ] **Без кэша и без сети.** На чистой тестовой установке открыть новости и документы без интернета. В обоих разделах после 10 секунд должна появиться плашка «Вне сети» без даты. Кнопка «Повторить» остаётся в сообщении об ошибке загрузки. Включить сеть и убедиться, что загрузка возобновилась.
- [ ] **Лента и статья из кэша.** С интернетом открыть ленту, несколько страниц и статью, дождаться картинок. Закрыть приложение, отключить сеть и открыть заново. Сохранённые данные и просмотренные картинки доступны, а через 10 секунд в плашке появляется время снимка. Ещё не открытая статья может требовать интернет. Для следующих сохранённых страниц можно использовать кнопку загрузки или повтора.
- [ ] **Документы из кэша.** С интернетом открыть список и детали документа, скачать файл. Перезапустить без сети. Ожидается: список и посещённые детали доступны из Room, скачанный файл открывается без сети.
- [ ] **Обновление без сети.** Потянуть вниз уже показанную ленту, статью, документы и расписание. Данные должны сохраниться, плашка продолжает показывать время снимка. При восстановлении сети плашка исчезает.
- [ ] **Ошибка сервера отличается от офлайна.** На тестовом сервере вернуть 503 при работающем интернете. Ожидается: ошибка обновления/сервера, без ложной надписи «Нет сети»; имеющийся контент остаётся.
- [ ] **Правильный кэш расписания.** С интернетом открыть две разные группы, затем преподавателя. Выключить сеть и переключаться между ними. Ожидается: каждый источник показывает только свой сохранённый снимок; для не посещённого источника — ошибка, а не расписание предыдущего.
- [ ] **Поиск и выбор расписания.** Без сети проверить поиск, онбординг и панель выбора. Ожидается: сохранённые справочники доступны, если они были загружены; ошибка/загрузка не выдаётся за успешный пустой справочник. Пустое избранное содержит подсказку.
- [ ] **Геометрия и доступность.** Проверить небольшой экран, альбомную ориентацию и увеличенный системный шрифт. Ожидается: контент прокручивается, нижняя навигация не закрывает кнопки файлов, сообщения не перекрывают управление; элементы имеют понятные подписи.

## Фиксация результата

Для ошибки записать: устройство и Android, шаг из этого списка, был ли интернет, посещался ли материал раньше, slug новости/документа, ожидаемый и фактический результат. Приложить скриншот. Для файлов также указать формат и статус DownloadManager. Не включать в отчёт личные файлы, токены и пароли.
