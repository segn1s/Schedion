# Результаты проверки реализации

## Автоматически

- `testDebugUnitTest`: 24 теста, 0 ошибок и пропусков.
- `lintDebug`: 0 ошибок, 12 предупреждений; проверки не отключались и baseline не добавлялся.
- `assembleDebug`: успешно.
- `assembleDebugAndroidTest`: успешно.
- На эмуляторе API 37 выполнены 9 инструментальных тестов, все прошли:
  - миграция Room 3 → 4 с сохранением избранного и чтением/записью новых таблиц;
  - четыре теста HTML: заголовки/сущности/жирный/курсив/цитаты, ссылки и изображения, вложенные нумерованные списки, некорректный HTML и script/style;
  - пагинация без дубликатов и сохранение показанных страниц при ошибке обновления;
  - отмена запроса предыдущей статьи;
  - обновление пустого состояния жестом;
  - реальный DownloadManager: скачивание публичного тестового PDF W3C, чтение content URI и сигнатуры PDF, повторное использование версии, повтор после удаления и отдельная загрузка новой версии.

Проверки Gradle выполнялись с `--offline --max-workers=1 --no-configuration-cache`: использован установленный кэш зависимостей, версии библиотек и SDK не менялись.

Проверка DownloadManager включается явно аргументом инструментального runner `-e networkChecks true`. Без него этот сетевой тест пропускается, чтобы стандартный прогон не зависел от внешнего сервера. Тест удаляет только собственные временные загрузки.

## Проверено на реальном API в эмуляторе

- Открываются лента с настоящими обложками и выбранная статья с HTML-текстом и изображениями.
- Пустой ответ документов отображается как «Документы пока не опубликованы».
- После отключения сети показанная лента и кэшированные изображения сохраняются; появляется плашка «Нет сети» с временем снимка.
- После восстановления сети успешное обновление убирает плашку.
- После обновления APK приложение открывает сохранённое расписание; аварии при открытии не обнаружены.

## Остаётся для полного ручного прогона

- Матрица реальных устройств Android 10 и Android 14.
- Отображение опубликованных документов всех категорий и реальных DOCX/XLSX: публичный сервер пока возвращает пустой список документов.
- Выбор внешних просмотрщиков и приложений-получателей через системные диалоги, увеличенный шрифт, альбомная ориентация и подготовленные ответы сервера 404/503.

Пошаговый список из 45 сценариев находится в [MANUAL_TESTING_NEWS_DOCUMENTS.md](MANUAL_TESTING_NEWS_DOCUMENTS.md). Невыполненные вручную сценарии в нём оставлены без отметок.
